# TAPMI Class Tracker

A free, mobile-friendly static web app built from the TAPMI MBA-AI&DS Batch 2025–2027 Term 5 timetable.

## Features
- Today view
- Next class
- Weekly timetable
- Date navigation
- Attendance tracker stored locally in the browser
- Installable PWA shell
- No paid backend and no external libraries

## Deploy free
1. Create a public GitHub repository.
2. Upload `index.html`, `data.json`, `manifest.webmanifest`, and `icon.svg`.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. Share the generated GitHub Pages URL with the batch.

## Notes
The timetable data covers the classes visible in the supplied Term 5 timetable. The app uses the browser's current date/time, so the Today/Next Class view updates automatically.
